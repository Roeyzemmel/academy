## Quote

> Suppose $\cQ$ is not $\cQ(-1^4)$, $\cQ(2,-1^2)$, or $\cQ(2^2)$. If $\cQ$ is not hyperelliptic, the only $\tilde{\cQ}$-periodic points are fixed points of the involution $J$. If $\cQ$ is hyperelliptic, the only $\tilde{\cQ}$-periodic points are fixed points for $J$ and fixed points for the hyperelliptic involution.
