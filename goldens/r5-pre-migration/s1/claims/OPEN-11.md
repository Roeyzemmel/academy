## Statement

5. Whether a $\Phi$-invariant nontrivial block system always exists — the missing
   ingredient that would turn S1 §3.5's one-step block reduction into an
   induction, since by Lemma 2.1 the block quotient inherits (A3). $\Phi$ is a
   2-group acting on the finite set of minimal block systems, so an odd number of
   them forces a fixed one; that is a condition, not a theorem.
