# Notation and conventions

> **This file is the domain's standard notation**, the default for a new home. It
> starts from mainstream usage in the translation-surfaces literature. Precedence is
> `academy:notation-discipline`'s: this pack < the project's decisions (for
> BilliardIllumination, `.claude/rules/notation-decisions.md`) < the draft itself. So a
> project that settles a different symbol keeps it, and this file is not rewritten to
> match one project; a change to the *domain* standard goes to Expert as a `notation`
> ticket (the librarian curates the pack). Items marked ⚑ are the ones most worth
> confirming against a project's drafts.

## Surfaces and strata

| Object | Notation | Notes |
|---|---|---|
| Translation surface | $(X,\omega)$ | $X$ a Riemann surface, $\omega$ a nonzero abelian differential |
| The surface as a metric/flat object | $M$ ⚑ | Common when the complex structure is not in play — e.g. LMW write $M$ throughout. Pick one of $M$ / $(X,\omega)$ as primary and use the other only where the distinction matters |
| Genus | $g$ | |
| Stratum | $\mathcal{H}(k_1,\dots,k_n)$ | zeros of orders $k_i$, $\sum k_i = 2g-2$ |
| Stratum with marked points | $\mathcal{H}(k_1,\dots,k_n,0^m)$ | $m$ marked points = zeros of order $0$ |
| Connected component | $\mathcal{H}^{\mathrm{hyp}}, \mathcal{H}^{\mathrm{odd}}, \mathcal{H}^{\mathrm{even}}$ | Kontsevich–Zorich |
| Area-one locus | $\mathcal{H}_1(\dots)$ | |
| Set of singularities / zeros | $\Sigma \subset X$ | $\Sigma(X,\omega)$ if disambiguation needed |
| Complex dimension | $\dim_{\mathbb C}\mathcal{H}(k_1,\dots,k_n) = 2g+n-1$ | the standing arithmetic check |
| Period coordinates | $\mathrm{H}^1(X,\Sigma;\mathbb{C})$ | relative cohomology; absolute periods $\mathrm{H}^1(X;\mathbb{C})$ |

Reserve $n$ for the number of zeros. If the paper also needs $n$ for a polygon's
side count or a covering degree, rename one of them ⚑ — this collision is a
frequent source of confusion in billiard papers.

## Flat geometry

| Object | Notation |
|---|---|
| Holonomy of a saddle connection $\gamma$ | $\mathrm{hol}(\gamma) = \int_\gamma \omega \in \mathbb{C} \cong \mathbb{R}^2$ |
| Set of saddle connections | $\mathcal{SC}(X,\omega)$, or $\mathcal{SC}_L$ for those of length $\le L$ |
| Holonomy vector set | $V(X,\omega) = \{\mathrm{hol}(\gamma)\}$ |
| Straight-line flow in direction $\theta$ | $\varphi_t^\theta$ |
| Cylinder | $C$; circumference $c(C)$, height $h(C)$, modulus $\mathrm{mod}(C)=h/c$ |
| Cylinder decomposition in direction $\theta$ | $X = \bigsqcup_i C_i$ (periodic direction) |
| Flat metric / distance | $d(\cdot,\cdot)$ |

Identify $\mathbb{C}$ with $\mathbb{R}^2$ silently but say so once, early.

## Groups and dynamics

| Object | Notation |
|---|---|
| Veech group | $\mathrm{SL}(X,\omega)$ ⚑ (alt: $\Gamma(X,\omega)$, $\mathrm{SL}(M)$) |
| Affine group | $\mathrm{Aff}(X,\omega)$ |
| Derivative map | $D:\mathrm{Aff}(X,\omega)\to \mathrm{SL}(X,\omega)$ |
| $\mathrm{GL}^+(2,\mathbb{R})$ action | $g\cdot(X,\omega)$ |
| Horocycle / geodesic flow | $u_s$, $g_t$ |
| Orbit closure | $\overline{\mathrm{GL}^+(2,\mathbb{R})\cdot(X,\omega)}$ |
| Affine invariant submanifold | $\mathcal{M}$ |
| Rank of $\mathcal{M}$ | $\mathrm{rank}(\mathcal{M})$ |
| Field of definition | $k(\mathcal{M})$ |

"Veech surface" = "lattice surface": $\mathrm{SL}(X,\omega)$ is a lattice in
$\mathrm{SL}(2,\mathbb{R})$. Fix one term and use it throughout ⚑.

## Billiards, unfolding, illumination

| Object | Notation |
|---|---|
| Polygon | $P$ (or $Q$ ⚑ — Wolecki uses $Q$; LMW's corollary uses $P$) |
| Rational polygon | all angles in $\pi\mathbb{Q}$ |
| Angle denominators / group | $N$; the dihedral/rotation group $D_N$ generated by the reflections |
| Unfolding of $P$ | $M_P$, or $\mathcal{U}(P)$ ⚑ |
| Billiard flow | $b_t$ |
| "$x$ illuminates $y$" | there is a straight-line (billiard) trajectory from $x$ to $y$ |
| Blocking set for $(x,y)$ | $B$; blocking cardinality $\mathrm{bc}(x,y)$ |
| Unilluminated set from $x$ | $\mathcal{U}(x) = \{y : x \text{ does not illuminate } y\}$ ⚑ (clashes with $\mathcal{U}(P)$ above — pick one) |
| Periodic point | a point with finite orbit under $\mathrm{Aff}(X,\omega)$ |

**Standing conventions to state once in the paper and then rely on:**

- Trajectories through singularities (or polygon corners) are **undefined**, not
  reflected. Say this explicitly; a large fraction of the subtlety in illumination
  statements lives here.
- Whether $x$ and $y$ are allowed to be singular / marked points, and whether $x=y$
  is permitted, must be fixed once. LMW require the blocking set to avoid $x$ and $y$.
- "Illuminate" is symmetric (reverse the trajectory), so "do not illuminate each
  other" is well-posed; write it symmetrically to make that visible.

## Typographic conventions

- Named theorems in `\cite`-anchored form: `Theorem~\ref{thm:lmw-blocking} of \cite{LMW16}`.
- Blackboard bold for $\mathbb{R},\mathbb{C},\mathbb{Z},\mathbb{Q},\mathbb{H}$;
  calligraphic for strata, moduli spaces, and affine invariant submanifolds
  ($\mathcal{H},\mathcal{M},\mathcal{SC}$); roman upright for operators
  ($\mathrm{hol}$, $\mathrm{mod}$, $\mathrm{Aff}$, $\mathrm{bc}$, $\mathrm{rank}$).
- Define every symbol at first use even when it is standard; readers enter a paper
  in the middle.
