## Statement

**Proposition 5.1.** Under (RD6), $m\ge5$: (a) $H^+\supseteq A_m$ iff $H^+$ is primitive and
contains a $3$-cycle. (b) If some corner type has exactly one reflex vertex, $H^+$ contains a
$3$-cycle. (c) Hence: $H^+$ primitive and one corner type with a unique reflex vertex ⇒ (HA)
(Lemma 3.2(b)) ⇒ Theorem 4.5 applies.
