## [R2 §4.5] The master criterion: relative 2‑transitivity with respect to $A$ and $Z$ (Proved)

Let $Z=C_{S_n}(G)$ (semiregular). For $(i,j)\in\Omega^{(2)}$ put $z(i,j)=T$ if $j=Ti$ for the
(unique) $T\in Z$, and $z(i,j)=\ast$ otherwise; $z$ is $G$-invariant. Define
$$\mathrm{inv}(i,j):=\big(d(i,j),\,z(i,j)\big)\in A\times(Z\cup\{\ast\}).$$
The level set of $(\delta,T)$, $T\in Z\setminus1$, is $\mathrm{gr}(T)$ if $\delta=d(i,Ti)$ and empty
otherwise; the level set of $(\delta,\ast)$ is $D_\delta\setminus\bigcup_T\mathrm{gr}(T)$.

> **(2T′)** every nonempty level set of $\mathrm{inv}$ is a single $G$-orbital.
> **(CT′)** (i) every $T\in Z\setminus1$ has a $T$-invariant $\langle u\rangle$-orbit for some $u\in W$; (ii) for every $\delta$ whose level set $(\delta,\ast)$ is nonempty, some $u^m$ with $m(q,p)\in\delta$ satisfies $u^mi\notin Zi$ for some $i$ (for $\delta=0$: $u^mi\notin Zi\cup\{i\}$).
